# PinBoard Keyboard Pro 2.0

یک برنامه مدیریت متن‌های آماده (Text Snippets) به همراه یک صفحه‌کلید سفارشی (IME) اندروید، نوشته‌شده با Kotlin.

## ✅ ویژگی‌های پیاده‌سازی‌شده

**بخش مدیریت (اپلیکیشن اصلی):**
- 🔍 جستجوی سریع در عنوان و متن پین‌ها (لحظه‌ای، هنگام تایپ)
- ⭐ علاقه‌مندی‌ها (تگل با یک لمس روی آیکون ستاره)
- 📂 دسته‌بندی متن‌ها با چیپ‌های قابل انتخاب (پویا، بر اساس دسته‌های موجود)
- 🕘 مرتب‌سازی بر اساس «آخرین استفاده» (پیش‌فرض)، «بیشترین استفاده» یا «الفبایی»
- 📊 نمایش شمارش دفعات استفاده روی هر پین
- ✏️ ویرایش پین با ضربه‌زدن روی آن
- 🗑️ حذف پین با نگه‌داشتن (Long Press) + دیالوگ تایید
- ذخیره محلی و کامل روی گوشی با Room (SQLite) — بدون نیاز به اینترنت

**بخش صفحه‌کلید سفارشی (PinBoard IME):**
- ⚡ درج مستقیم متن با یک لمس (بدون کپی/پیست دستی)
- 🔍 نوار جستجوی مستقل داخل خود کیبورد
- 📂 فیلتر دسته‌بندی از داخل کیبورد (چیپ‌های قابل انتخاب)
- ⭐ فیلتر «فقط علاقه‌مندی‌ها» از داخل کیبورد
- 🗑️ حذف پین با نگه‌داشتن روی آن، مستقیماً از داخل کیبورد
- ⚙️ دکمه ورود مستقیم به صفحه مدیریت پین‌ها
- 🇮🇷 رابط کاملاً فارسی و راست‌به‌چپ (RTL) در هر دو بخش
- 🎨 ظاهر مدرن با Material Components (کارت‌ها، چیپ‌ها، رنگ‌بندی یکدست)

## 📂 ساختار پروژه

```
PinBoardKeyboardPro/
├── app/
│   └── src/main/
│       ├── kotlin/com/pinboard/keyboard/
│       │   ├── data/       -> Pin, PinDao, AppDatabase, PinRepository (Room)
│       │   ├── ui/         -> MainActivity, PinAdapter, PinViewModel, EditPinDialog
│       │   ├── keyboard/   -> PinBoardIME (InputMethodService), KeyboardPinAdapter
│       │   └── util/       -> SortMode و ثابت‌ها
│       ├── res/            -> layout ها، آیکون‌های وکتور، رنگ‌ها، رشته‌های فارسی
│       └── AndroidManifest.xml
├── build.gradle
├── settings.gradle
└── gradle.properties
```

## 🚀 راه‌اندازی

1. پوشه پروژه را در **Android Studio** باز کنید (File → Open).
2. اجازه دهید Android Studio هنگام Sync، فایل‌های Gradle Wrapper گم‌شده را بازسازی کند
   (چون این پروژه بدون فایل باینری `gradle-wrapper.jar` ارسال شده — Android Studio معمولاً
   خودش پیشنهاد «Repair» یا «Sync» می‌دهد؛ در غیر این صورت از `gradle wrapper` محلی خودتان استفاده کنید).
3. دستگاه/شبیه‌ساز را با حداقل Android 7.0 (API 24) وصل کنید و Run بگیرید.
4. برنامه نصب می‌شود. برای فعال‌سازی کیبورد:
   - وارد **تنظیمات گوشی → زبان و ورودی → صفحه‌کلیدهای مجازی** شوید.
   - **PinBoard Keyboard Pro** را فعال کنید.
   - در هر فیلد متنی، از دکمه تعویض کیبورد آن را انتخاب کنید.

## 💾 ذخیره‌سازی

تمام داده‌ها (پین‌ها، دسته‌بندی‌ها، تعداد استفاده، وضعیت علاقه‌مندی) به‌صورت کامل و محلی
در یک پایگاه‌داده Room/SQLite روی خود گوشی ذخیره می‌شوند و هیچ داده‌ای به سرور ارسال نمی‌شود.
برنامه اصلی و سرویس کیبورد از یک پایگاه‌داده مشترک استفاده می‌کنند، پس هر تغییری در یکی
بلافاصله در دیگری هم منعکس می‌شود.

## 🧭 مراحل بعدی پیشنهادی (طبق ایده شما)

برای تبدیل این پروژه به یک کیبورد کاملاً حرفه‌ای در سطح Gboard برای متن‌های آماده، گام‌های
بعدی می‌توانند این‌ها باشند (در نسخه فعلی پیاده‌سازی نشده‌اند):

- تب‌های جداگانه «اخیر / علاقه‌مندی / دسته‌ها» به‌جای فیلتر تکی
- پشتیبانی از ایموجی و برچسب‌گذاری پین‌ها
- Drag & Drop برای تغییر ترتیب دستی پین‌ها
- Backup / Restore (خروجی و ورودی JSON از پین‌ها)
- طراحی گرافیکی پیشرفته‌تر خود صفحه کیبورد (انیمیشن، تم تیره/روشن)

اگر بخواهید می‌توانم در همین گفتگو یکی‌یکی این موارد را روی پروژه فعلی اضافه کنم.
